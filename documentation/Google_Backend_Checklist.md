## Search Console

- 確認正式網域資源、管理權及 HTTPS／www 的網址版本。
- 提交 `https://www.hlaglobal.com.tw/sitemap.xml`；本版列出57個可索引網址。
- 使用網址檢查抽查首頁、八大服務、代表文章及四個列表頁，確認 Google 選擇的 Canonical、可索引狀態與實際抓取結果。
- 舊 `insights-category.html` 已設為 noindex,follow，不列入 Sitemap。分類 fragment 不作獨立收錄目標。
- 比較相同長度與相同搜尋類型的期間，分別記錄品牌與非品牌曝光、點擊、CTR、平均排名及到達頁。
- 關鍵字表是依附件策略配置的候選意圖，不是搜尋量或實際排名研究。應依後台資料與接案方向調整。

## GA4 與實際詢問

保留 V5.1 的 `G-D6FG3MXEYP` 設定。此公開 ID 沿用母版，不代表本次已確認該資源所有權或即時接收狀況。

分析只在正式來源、同意分析且符合查詢參數限制時啟動。新增事件僅接受固定分類、交通模式及公開頁面路徑；不要將案件文字、聯絡資訊、站內搜尋文字或其他當事人資料加入事件參數。

| 事件 | 功能 | 驗證方式 |
| --- | --- | --- |
| view_practice | 服務頁瀏覽 | 同意後以 DebugView 檢查 |
| view_lawyer | 律師頁瀏覽 | 同意後以 DebugView 檢查 |
| view_article | 文章瀏覽 | 每次頁面載入僅記錄一次 |
| article_to_service | 文章前往服務 | 點擊文章內對應服務連結 |

目前 `intakeMode` 仍為 `local-summary`，與 V5.1 相同。整理或下載摘要不代表已將案件送交事務所，也不應當作已完成的有效法律諮詢。

管理者應核對 GA4 的加強型評估設定，避免自動表單或其他自訂追蹤讀取使用者輸入。正式發布後，以同意、拒絕、撤回同意及含私人搜尋參數的情況逐一確認。

若從商家連到官網時使用 UTM，本版原有隱私機制會因非白名單查詢參數停止分析。未經設計與測試，請先使用乾淨官網網址，並以商家後台記錄網站點擊及導航，不要為歸因直接放寬隱私條件。
