## 原有內容保留方式

原始主樣式 `main.min.css`、圖片與字型保持位元組一致，補充樣式放在 `seo-v52.css`。八大服務保留既有主視覺、情境卡、判斷架構、階段頁籤及 FAQ；新增內容沿用網站既有色彩、字體與間距。

32 篇文章沒有刪除或整併。搜尋任務以 `keyword-intent-matrix.csv` 區分；標題相近的親權與生活安排、繼承盤點與遺產分割、扶養費計算與追討，各自保留不同的問題定位。

原有作者、審核署名、發布日期、法規來源與主要法律內文保留。「頁面更新」標示本次導覽與資料整理日期，不表示已完成新一輪律師法律審核。

## 索引與篩選的分工

`insights.html`、`insights-2.html`、`insights-3.html`、`insights-4.html` 為收錄對象，各有八篇可直接讀取的文章卡、分頁連結與自己的 Canonical。

`#category=...` 只表示瀏覽器內的分類篩選。選定分類後顯示該類全部文章，並連到對應的服務頁；沒有使用 fragment 作為可收錄的分頁網址。未啟用 JavaScript 時仍可透過四個 HTML 列表頁取得全部文章。

外部既有 `?category=` 連結於程式啟動後轉為分類狀態，Canonical 保持不帶參數；若同時含其他查詢參數，程式不會任意刪除，以維持原有分析隱私限制。
