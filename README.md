# HLA Global Website｜三語系 V5（2026-11-21）

本 ZIP 是可直接部署的完整靜態網站，支援繁體中文、English、日本語。以 V4 完整網站為母版，保留原有設計、圖片、法律觀點、八大專業領域、律師團隊、地圖、表單及 SEO 設定。

## 這次修改

- 導覽列：移除放大鏡搜尋入口（含手機版），其餘主要分頁與預約按鈕保留。
- 右上角 `Language`：按鈕間距與寬度再縮減，三語系切換照常使用。
- 桌面導覽標題：維持相對原始 1rem 放大 5% 的字級；選取與滑鼠移入時的底線貼近文字。
- 八大專業領域：**英文與日文的 8 個詳細服務頁面均已逐段完成翻譯**，包含服務說明、具體服務內容、流程、FAQ、延伸閱讀區塊及動態流程文字。
- 保留中文版內容與英日文的完整版面結構；移除舊版用來代替全文翻譯的額外簡介框。

## 如何部署

將 ZIP 解壓縮後，**把 `index.html`、`assets/`、`en/`、`ja/` 與其餘檔案資料夾一起放在網站根目錄**。不要把 ZIP 檔名資料夾加在網址路徑中；不要只上傳 `en/` 與 `ja/`。

本版本已更換語系 CSS 版本參數以降低舊版快取影響。網站本身是 HTML/CSS/JavaScript，不需重新編譯。預約功能、LINE、Google 地圖、外部服務必須在正式或測試網域實際驗收。
